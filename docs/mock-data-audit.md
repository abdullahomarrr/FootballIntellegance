# Mock and placeholder data audit

Audit date: 2026-09-30. Test fixtures are acceptable; normal application routes must not
present them as observations.

| Path | Feature/purpose | Classification | Acceptable? | Current disposition |
|---|---|---|---|---|
| `tests/**` | Deterministic candidates, HTTP payloads, events, articles and failure cases | TESTING | Yes | Isolated from production tables and UI |
| `config/identity-overrides.example.json` | Documents override shape | DOCUMENTATION FIXTURE | Yes | Never executed automatically |
| `data/coverage/*.json` | Dated real provider discovery snapshots | GENERATED REAL ARTIFACT | Yes | Retained with provider timestamps |
| `data/canonical/events/*.jsonl` | Reproducible normalized outputs | GENERATED REAL ARTIFACT | Yes | Derived from immutable raw provider responses |
| `data/reports/*.json` | Ingestion/validation evidence | GENERATED REAL ARTIFACT | Yes | Regenerated by CLI workflows |
| `src/football_intelligence/sentiment.py` | Small deterministic lexicon | UNVALIDATED BASELINE | Only as explicit user-text context | API/UI label it `EXTERNAL_CONTEXT_ONLY`; no stored fake sentiment |
| `src/football_intelligence/valuation.py` | Availability and temporal contract | PLACEHOLDER | Yes only because it fails closed | Returns null estimate/interval and `LICENSED_TARGET_REQUIRED` |
| Recruitment POST candidate contract | Caller-supplied pure ranking contract | DEVELOPMENT/API CONTRACT | Not a source of facts | Production UI uses database-backed `GET /players/{id}/similar` |
| Squad POST candidate contract | Caller-supplied optimizer contract | DEVELOPMENT/API CONTRACT | Not a source of facts | Production UI shows data gate and sends no synthetic players or prices |

## Removed production mocks

- Recruitment no longer embeds “Wide creator” or “Direct winger” records, invented ages,
  values, minutes, or feature vectors.
- Squad planning no longer embeds fictional wingers/strikers, costs, or fit scores.
- Market intelligence no longer submits a hardcoded positive sentence.
- Analysis no longer submits hardcoded trait vectors, minutes, dated development values or
  user-provided JSON. It searches canonical players and loads real qualified season metrics.
- Similar-player API no longer always returns an empty placeholder; it queries real qualified
  player-season percentiles.

## Search conclusion

Words such as `sample` in confidence descriptions, `fixture` for football matches, temporary
atomic-write paths, and mocked provider responses under `tests/` are not production mock data.
The final production-path scan found no normal frontend route that silently presents a
fictional footballer, market value, transfer, article, social aggregate, sentiment observation,
or model prediction. User-created role and shortlist names are workflow records, not observations.
