# StatsBomb Open Data

- Access: public GitHub repository; no credential.
- License/terms: repository terms and attribution requirements must be reviewed at each refresh.
- Used endpoints/files: competitions, matches, events and lineups JSON.
- Grain: competition-season catalogue, match, lineup player and event.
- Canonical mapping: StatsBomb 120 × 80 coordinates are retained raw and normalized to 105 × 68 metres; native `statsbomb_xg` remains provider data.
- Known limits: selected competitions/seasons; a catalogue row does not prove full fixture coverage. Match counts are persisted and completeness is never implied.
- Current evidence: match 3754217, 3,732 canonical events; Big Five discovery artifact and 81 database coverage observations.

Attribution must accompany redistributed outputs where required. The open repository is not treated as live 2026/27 coverage.
