## Honest non-completion boundary

The repository cannot truthfully claim broad live 2026/27 coverage, a trained market valuation model, or production news/social sentiment without credentials, accepted terms and licensed data. The code fails closed for those capabilities. Synthetic records remain in tests only and are never represented as production observations.
